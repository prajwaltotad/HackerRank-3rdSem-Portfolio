# HackerRank Problem Solving – Studio Activity

This repository contains my solutions to the **5 mandatory HackerRank problems** assigned as part of the CSE studio activity.

The objective of this activity is to strengthen problem-solving skills, practice fundamental data structures and algorithms, analyze time and space complexity, and maintain a clean GitHub portfolio.

## 📌 Problems Covered

| # | Problem                                                                                    | Topic                     | Time     | Space |
| - | ------------------------------------------------------------------------------------------ | ------------------------- | -------- | ----- |
| 1 | [Diagonal Difference](https://www.hackerrank.com/challenges/diagonal-difference/problem)   | 2D Arrays / Matrices      | O(N)     | O(1)  |
| 2 | [Dynamic Array](https://www.hackerrank.com/challenges/dynamic-array/problem)               | Data Structures / Vectors | O(N + Q) | O(N)  |
| 3 | [Time Conversion](https://www.hackerrank.com/challenges/time-conversion/problem)           | Strings & Logic           | O(1)     | O(1)  |
| 4 | [Compare the Triplets](https://www.hackerrank.com/challenges/compare-the-triplets/problem) | Basic Implementation      | O(1)     | O(1)  |
| 5 | [Sparse Arrays](https://www.hackerrank.com/challenges/sparse-arrays/problem)               | Hash Maps / Strings       | O(N + Q) | O(N)  |
